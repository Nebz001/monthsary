<br>

> 💌 A small website made for babyy for our monthsary on **October 20**.
> It opens with a heart shaped padlock, and once she enters the day she said yes, it unlocks three little gifts: **our photos**, **a letter**, and **our song**.
>
> It is a static site hosted for free on GitHub Pages. No server, no database.
